# Pathogenic Germline Variants, Family History, and Breast Cancer Risk by Menopausal Status

## Overview

This repository contains statistical analysis and figure-generation scripts associated with the manuscript *Pathogenic Germline Variants, Family History, and Breast Cancer Risk by Menopausal Status*. The study examines the joint associations of pathogenic germline variants (PGVs) and breast cancer family history with breast cancer risk in Japanese women, including analyses by menopausal status.

The scripts document the analyses used for the manuscript's main tables, supplementary tables, and figures. **The restricted participant-level data are not included**, and full reproduction of the analyses requires authorized access to the study datasets.

## Data availability

Individual-level genetic, family history, and clinical data are not publicly available because access is subject to participant consent and institutional ethics and data-governance requirements. Requests for access to de-identified data may be considered through the appropriate institutional review and approval processes. Public availability of this code does not grant access to the underlying data.

The original input datasets and an intermediate participant-level dataset generated during analysis are **not included** in this repository. Authorized users must supply the appropriate datasets and configure local input/output paths before running the relevant scripts.

## Repository contents

| Script | Description |
| --- | --- |
| `01_Main_tables_and_supplementary_analyses.do` | Constructs the analytic dataset, defines PGV groups and reference categories, and runs analyses for Tables 1–3 and eTables 2–9. The predefined gene groups corresponding to eTable 1 are specified here. Joint-category odds ratios and factorial interaction models are fitted separately. |
| `02_Figure_1_forest_plot.R` | Creates Figure 1 using manually specified final odds ratios, confidence intervals, and interaction P values from the statistical analyses. |
| `03_Figure_2_PGV_distribution.do` | Creates Figure 2 using an intermediate participant-level dataset produced by the main analysis script. |
| `04_eFigure_2_PGV_prevalence_by_age.do` | Produces the prevalence-by-age analysis and eFigure 2 from restricted study data. |
| `05_eFigure_3_TNBC_by_BRCA_menopause.do` | Creates eFigure 3 from aggregate counts obtained in the breast cancer subtype analyses. |

**Note:** eFigure 1 is a participant-selection flow diagram and is not generated by a separate script in this repository. The Figure 1 and eFigure 3 scripts visualize analysis results supplied within the scripts; they do not independently estimate those results from the raw participant-level datasets.

## Software and dependencies

- Stata 18 for the `.do` files. The Firth penalized logistic regression sensitivity analyses require the user-written Stata command `firthlogit`.
- R for the Figure 1 script, with packages `ggplot2`, `dplyr`, `tidyr`, `grid`, and `patchwork`.

R package versions are not pinned in this repository.

## Running the scripts

1. Obtain authorized access to the required source data and configure the input/output paths in the scripts for your local environment.
2. Run `01_Main_tables_and_supplementary_analyses.do` to generate the main analyses and the intermediate dataset required for Figure 2.
3. Run `02_Figure_1_forest_plot.R` to create Figure 1 from the embedded final estimates.
4. Run `03_Figure_2_PGV_distribution.do` to create Figure 2 from the intermediate dataset.
5. Run `04_eFigure_2_PGV_prevalence_by_age.do` to create eFigure 2 from the restricted source data.
6. Run `05_eFigure_3_TNBC_by_BRCA_menopause.do` to create eFigure 3 from the embedded aggregate counts.

For each PGV group, the reference category comprises participants with no PGV in any of the 27 evaluated genes. Participants carrying PGVs only in genes outside the group being evaluated are not assigned to that group’s noncarrier category.

The scripts use generic input filenames (`study_input.dta` and `subtype_input.dta`) and generate `analysis_intermediate.dta` locally. Authorized users should map these placeholders to their approved local data sources. The scripts require the original variable structure and are not executable without the restricted input data. No participant-level dataset should be committed to a public repository.

## Reproducibility and limitations

These scripts provide the analysis specifications and figure-generation procedures used in the study. Analyses requiring restricted individual-level data cannot be executed using this repository alone. Figures generated from embedded estimates or aggregate counts can be produced without access to participant-level data, but those scripts do not independently verify the source estimates.
